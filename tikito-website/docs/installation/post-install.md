# Post installation

These steps will help you getting started with Tikito.

## Step 1 - Register the admin user
Open [http://localhost:8080](http://localhost:8080) and you will see the screen below to register the admin user.

![](/tikito-screenshots/initial-installation.png)

Fill in the fields to register and finish setting up Tikito.

## Step 2 - Create account
You can now create an account. It can be either a debit account or for your stock portfolio.

From here you can either continue with importing your [stock portfolio](/docs/installation/import-security), or you [banking transactions](/docs/installation/import-money).
