# Import banking transactions

After creating an account for your bank, you can import the export file from your bank.

## Step 1 - Export from your bank

Download a transaction export from your bank's online portal. See [supported file formats](/docs/importing/money) for which banks and formats are supported.

## Step 2 - Import into Tikito

Click **Import** in the top navigation. Select the account you created and upload the file you downloaded. Tikito will automatically detect the bank format where possible.

If your bank is not recognised, Tikito will ask you to map the column names in your file to the expected fields.

## Step 3 - Create money groups (optional)

To categorise your transactions (e.g. "Groceries", "Salary", "Rent"), create **money groups** by clicking **Money groups** in the top navigation.

Each group uses one or more qualifiers to match transactions by description, counterparty name, or counterparty account number. See [Money graph](/docs/features/money-graph) for details.

## Step 4 - Apply grouping

After creating groups, go to **Admin → Money** to apply the grouping rules to your existing transactions.

## Visualise

Go to **Money** in the top navigation to see the balance history graph for your account.
