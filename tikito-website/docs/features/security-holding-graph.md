# Security holding graph

The security holding graph visualises the market value of your investment portfolio over time.

## What it shows

The graph plots the [historical value](/docs/concepts/historical-value) of each security holding and the [aggregated historical value](/docs/concepts/aggregated-historical-value) across all securities. You can see how your portfolio has grown or declined and drill into individual positions.

## Portfolio overview

The securities overview page shows a table of all your current holdings with:

- Number of shares held
- Average buy price
- Current market price
- Unrealised gain / loss (absolute and percentage)
- Total return including dividends

Click on any position to expand it and see the transaction history. Double-click to open the detailed graph view for that security.

## Filtering

You can filter the graph by:

- **Date range** — preset ranges or a custom start and end date
- **Accounts** — select which broker accounts to include
- **Show closed positions** — toggle whether to display holdings where you have sold all shares

## Individual security graph

The detail graph for a single security shows:

- The value of your position over time
- Buy and sell markers on the timeline
- Dividend income over time
- The number of shares held over time

## Nightly price updates

Security prices are updated automatically every night. After the update, historical values are recalculated and the graph will reflect the latest prices the next time you load it. You can also trigger a manual price fetch from the Admin panel.
