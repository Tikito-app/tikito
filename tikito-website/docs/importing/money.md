# Money transactions

## File types
However, each source might also supply different types of files.
Tikito supports the following file formats:
- Csv
- Excel
- MT940

## Sources
Tikito supports the following sources:
- [ABN AMRO](https://www.abnamro.nl/nl/zakelijk/internet-bankieren/bestanden-downloaden.html), both MT940 and Excel
- [ING](https://www.ing.nl/particulier/digitaal-bankieren/afschriften-downloaden)

However, Tikito also supports a generic import using csv or Excel. 
If the source could not be determined, you might still be able to import it.
